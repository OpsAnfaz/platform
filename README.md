# OpsAnfaz
OpsAnfaz es una plataforma SaaS cloud-native construida sobre AWS,
diseñada para demostrar infraestructura empresarial real con Terraform,
Kubernetes y GitOps.


## Stack tecnológico
Terraform, CD/CI, Cloud Infra
